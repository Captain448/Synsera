# Synsera

## AI-Powered Employee Wellbeing & Burnout Detection Platform

Synsera is a full-stack AI-powered employee wellbeing monitoring platform designed to help organizations identify burnout risks, track employee sentiment, and generate actionable insights for managers and HR teams.

The platform uses Natural Language Processing (NLP), sentiment analysis, and AI-driven assessments to analyze employee feedback and provide personalized as well as team-level wellbeing recommendations.

---

## Problem Statement

Employee burnout, stress, and declining job satisfaction often go unnoticed until they significantly impact productivity and retention. Traditional surveys are time-consuming and fail to provide actionable insights.

Synsera addresses this challenge by enabling continuous wellbeing monitoring through intelligent assessments and AI-powered analysis.

## Installation

### Clone Repository

```bash
git clone https://github.com/your-username/Synsera.git
cd Synsera
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file:

```env
API_KEY=YOUR_GEMINI_API_KEY
```

### Run the Project

```bash
npm run dev
```
